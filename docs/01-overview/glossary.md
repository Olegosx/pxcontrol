## Назначение документа

Единый список терминов проекта, чтобы все (люди и ассистенты) понимали
слова одинаково. При первом употреблении термина в других доках —
ссылаться сюда.

## Термины (заполнять по мере появления)

| Термин | Расшифровка / определение |
|---|---|
| **Bot API** | Официальный HTTP-интерфейс Telegram для ботов. В приложении — запасной путь публикации (до 50 МБ, только «сейчас», ADR-0011) и служебные проверки. |
| **MTProto** | Низкоуровневый протокол Telegram для клиентов (userbot). Используется как второй транспорт наряду с Bot API — для чтения/парсинга каналов и опц. планирования (см. ADR-0007). Работает на отдельном аккаунте. |
| **userbot** | Автоматизация от имени пользовательского аккаунта Telegram (через MTProto), а не бота. Даёт чтение чужих каналов, но несёт риск блокировки аккаунта. |
| **session string** | Строка сессии MTProto — по силе равна паролю аккаунта; хранится зашифрованно, не попадает в код и логи. |
| **Сообщество** | Центральная сущность приложения (`Community`, ADR-0021): подключённый канал или группа Telegram. Вид (`kind`) определяется при подключении; публикаторы — userbot и/или бот. |
| **Канал** | Вид сообщества: канал-вещалка. Публикует администратор с правом `post_messages`. |
| **Группа** | Вид сообщества: супергруппа. Публикует любой участник, не ограниченный в отправке; малые (не супер-) группы не подключаются. |
| **Тема форума** | Отдельная лента в группе с включёнными темами; адресуется id корневого сообщения (`topic_id`). «General» (id 1) — общая лента. Список тем читает только userbot; в закрытую тему пишет только админ. |
| **Участник (членство)** | Userbot-аккаунт, состоящий в сообществе (`community_members`, ADR-0022), с ролью `admin`/`member` из зондов прав. Пул участников — фундамент модуля соцактивности. |
| **Публикатор по умолчанию** | Аккаунт-участник, от имени которого идут публикация, отложки и темы (`default_tg_account_id`). Меняется только явно. |
| **Пост** | Единица контента для публикации (текст, медиа, кнопки). |
| **Источник** | Внешний поставщик контента: другой канал, сайт или RSS-лента. |
| **Очередь модерации** | Список заготовок контента, ожидающих одобрения человеком. |
| **Планировщик** | Своего компонента нет (ADR-0010): отложенные записи хранит и публикует сервер Telegram; страница «Расписание» лишь читает их из канала. |
| **Очередь отправки** | Персистентная очередь публикации (ADR-0016, таблица `publish_queue_items`): посты уходят последовательно, с прогрессом и отменой; сверх лимита 100 отложек — ждут слота. |
| **Пресет** | Сохранённый набор параметров обработки видео (обрезка, вотермарк, заставка, битрейт, подпапка). |
| **Подпись** | Текст к посту, собираемый по шаблону из полей со словарями («**название** + Поле: #значения»). |
| **Отложенный постинг** | Публикация поста в будущем по расписанию, а не сразу. |
| **Рерайт** | Переписывание исходного материала перед публикацией (часто с помощью ИИ). |
| **ADR** | Architecture Decision Record — запись о принятом архитектурном решении. |
