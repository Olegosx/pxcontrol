## Этап 1. MVP — видео-пост вручную

- [x] Подключение канала: через userbot или бота, проверка прав,
      управление доступами (2026-07-12, доступы — 2026-07-14).
- [x] Подготовка видео (порт `makeVideo`): FullHD, вотермарк, заставка,
      обложка; пресеты; страница «Видео» (2026-07-12).
- [x] Публикация всех типов контента (`PostDraft`): userbot в приоритете,
      бот — запасной путь; «сейчас» и отложенно — сервер Telegram
      (ADR-0010, ADR-0011, 2026-07-14). Шаблоны подписей и имён файлов.
- [x] Пресет обработки по умолчанию для канала: настройка в карточке
      канала, подстановка на странице «Видео» (ADR-0013, 2026-07-16).
- [x] Пакетная обработка видео: рекурсивное сканирование папки, выбор
      файлов галочками, очередь обработки с прогрессом и отменой,
      подпапка пакета в результатах (ADR-0014, 2026-08-15).
- [x] Пакетная отправка: черновики постов из готовой папки, подписи
      по общему шаблону, раскладка времени стратегиями, правка
      построчно, атомарная постановка в очередь (ADR-0015, 2026-08-15).
- [x] Очередь сверх лимита отложек Telegram (100/канал): персистентная
      очередь отправки, ожидание слота, папка очереди на диске
      (ADR-0016, 2026-08-26).
- [x] Полный просмотр очереди отправки: кнопка «Вся очередь…»
      на «Публикации» — живой список со всеми элементами, сортировка
      (ближайшие/постановка/по каналам) и фильтры (статус, канал);
      на странице — ближайшие 20 карточек и сводка (2026-08-26;
      с 2026-09-17 — экран «Очередь» раздела «Публикация»).
- [x] Отложенные записи как очередь: правка текста и времени,
      «Сейчас» и «Удалить» на сервере Telegram; «Отложено» и «Очередь» —
      два списка одного вида; общий список карточек
      (ADR-0028, 2026-09-15; место в навигации — ADR-0032).
- [x] Обслуживание сообществ: чистка служебных записей и удаление
      мёртвых аккаунтов; под ними — общий каркас заданий движка
      и дорожка аккаунта Telegram (ADR-0024/0025/0026, 2026-09-12).
- [x] Кнопки под постом: публикует публикатор, разметку дорисовывает
      бот; у отложенных — выбор режима «публикация/кнопки важнее»;
      пределы клавиатуры проверяет приложение (ADR-0031, 2026-09-16;
      маршруты — [publishing-routes.md](../03-modules/publishing-routes.md)).
      Не сделано намеренно: склад (Р3) и отложенная пересылка (Р5) —
      нужны только кнопкам у крупных файлов в режиме «кнопки важнее».
- [ ] Раздел «Публикация» по стадиям жизни поста (ADR-0032, подачи
      A1–A4). Сделано:
      - [x] **A1** — раздел с веткой подменю, экраны «Новый пост ·
            Очередь · Отложено», раздел «Расписание» снят, владение
            очередью отправки вынесено из формы поста в наблюдателя
            при главном окне (2026-09-17).
      - [x] **A2** — «Пакет» отдельным экраном: свой адресат (сообщество
            и тема), кнопки под постом на весь пакет, общий блок
            адресата с формой поста (2026-09-17).
      - [x] **A3** — экран «Опубликовано»: чтение ленты страницами

      - [ ] **A4** — действия на «Опубликовано»: правка текста
