- [x] Подготовка видео (порт `makeVideo`): FullHD, вотермарк, заставка,

- [x] Публикация всех типов контента (`PostDraft`): userbot в приоритете,
      бот — запасной путь; «сейчас» и отложенно — сервер Telegram
      (ADR-0010, ADR-0011, 2026-07-14). Шаблоны подписей и имён файлов.
- [x] Пресет обработки по умолчанию для канала: настройка в карточке
      канала, подстановка на странице «Видео» (ADR-0013, 2026-07-16).
- [x] Пакетная обработка видео: рекурсивное сканирование папки, выбор
      файлов галочками, очередь обработки с прогрессом и отменой,
      подпапка пакета в результатах (ADR-0014, 2026-08-15).
- [x] Пакетная отправка: черновики постов из готовой папки, подписи
      по общему шаблону, раскладка времени стратегиями, правка
      построчно, атомарная постановка в очередь (ADR-0015, 2026-08-15).
- [x] Очередь сверх лимита отложек Telegram (100/канал): персистентная
      очередь отправки, ожидание слота, папка очереди на диске
      (ADR-0016, 2026-08-26).
- [ ] Полный просмотр очереди отправки: кнопка на «Публикации»,
      сортировка и фильтры (следующий срез ADR-0016; на странице —
      ближайшие 20 карточек и сводка).
