# Стандарты кода

> Статус: 🟡 черновик-заглушка · Обновлено: 2026-06-30 · Владелец: olegosx

## Назначение документа

Зафиксировать правила оформления кода для `pXcontrol`. Базовые стандарты
заданы глобально в личном `~/.claude/CLAUDE.md` и имеют приоритет; здесь —
их краткая выжимка и проектные дополнения.

## Базовые правила (из глобального стандарта)

- Python 3.x, **строгая типизация** (type hints везде).
- Имена: `snake_case` для переменных/функций, `PascalCase` для классов.
- Docstrings (Google-style) для всех публичных функций и классов.
- Максимум **30 строк** на функцию; длиннее — рефакторить.
- Принципы DRY, KISS, YAGNI.
- Явная обработка ошибок — никогда не глотать исключения молча.
- Логирование через `logging`, не `print`. f-строки для форматирования.
- Отступы — табы (где синтаксис позволяет).

## Вёрстка экранов (Qt)

- **У вертикальной компоновки экрана внизу обязательна растяжка**
  (`layout.addStretch()`). Без неё лишняя высота окна распределяется
  между виджетами, и подписи с переносом слов (`setWordWrap(True)`)
  раздуваются на сотни пикселей: текст рисуется по центру пустоты,
  а форма выглядит разорванной. Исключение — экран, где лишнее место
  осознанно отдано списку (тогда у списка `stretch=1`, а растяжка
  снизу остаётся с нулевым весом).
- **Ветки подменю навигации чинит окно.** QFluentWidgets 1.11.3 при
  смене ширины панели назначает каждому пункту высоту в одну строку
  (`NavigationWidget.setCompacted`), и ветка теряет место под своих
  детей — они налезают друг на друга. Обход живёт в одной точке
  (`MainWindow._fix_branch_sizes`), библиотека при этом не правится.
- **Проверка — пробой, а не глазами**: `_misc/ui_layout_probe.py`
  собирает окно вне экрана, обходит все страницы и сообщает о раздутых
  подписях и наложении пунктов. Прогонять после правок вёрстки:

      QT_QPA_PLATFORM=offscreen .venv/bin/python _misc/ui_layout_probe.py
