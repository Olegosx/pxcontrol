# Настройка окружения разработчика

> Статус: 🟢 готов · Обновлено: 2026-08-15 · Владелец: olegosx

## Назначение документа

Пошаговая инструкция, как поднять проект локально для разработки.
Команды запуска дублируются в [README.md](../../README.md) (раздел
«Запуск») — при изменении обновлять оба места.

## Шаги

1. **Python 3.11+** и менеджер окружений **uv** (подойдёт и `pip + venv`):

   ```bash
   uv venv && uv pip install -e ".[dev]"
   ```

   Окружение привязано к абсолютному пути: после переноса папки проекта
   его нужно пересоздать (шебанги скриптов в `.venv/bin` хранят старый
   путь к интерпретатору).

2. **ffmpeg/ffprobe** — установить в системе (обработка видео);
   путь можно указать в «Настройки → Общие» или бутстрапом `FFMPEG_PATH`.

3. **Настройки:** `cp .env.example .env` — в `.env` только бутстрап
   (`DATABASE_URL`, `FFMPEG_PATH`, `LOG_LEVEL`); секреты и рабочие
   настройки живут в БД ([ADR-0009](../02-architecture/decisions/0009-config-secrets-in-db.md),
   [ADR-0013](../02-architecture/decisions/0013-settings-storage.md)).

4. **БД SQLite** — локальный файл `pxcontrol.db`, создаётся и мигрирует
   автоматически при старте (`Database.init()`).

5. **Запуск:** `.venv/bin/pxcontrol` или `python -m pxcontrol` —
   откроется окно; порядок старта — [runtime.md](../02-architecture/runtime.md).

6. **Проверки перед коммитом:**

   ```bash
   ruff format src tests && ruff check src tests
   mypy src
   pytest
   ```

## Требования

- Тестовый Telegram-бот (токен от @BotFather) и тестовый канал.
- Отдельный userbot-аккаунт (api_id/api_hash с my.telegram.org) —
  публикация идёт в первую очередь через него (ADR-0011).
- Ключ провайдера ИИ — только для будущих функций генерации.
